# Учебный программный комплекс по планированию режима работы ГЭС

Настольное приложение на Python и PyQt5 для подбора режима работы Воткинской ГЭС с учётом требований водопользователей. Режим наносится на поле диспетчерского графика, результаты выгружаются в книгу MS Excel.

Комплекс разработан в 2019 году в рамках магистерской диссертации автора на кафедре ГВИЭ НИУ «МЭИ» (Москва).

English version: [educational_software_hpp_en](https://github.com/alexshep-lab/educational_software_hpp_en).

## Возможности

- выбор варианта исходных данных и ограничений водопользователей;
- расчёт долгосрочного и среднесрочного режима работы ГЭС;
- отображение режима на поле диспетчерского графика;
- выгрузка отчётной формы в Excel (`xlsxwriter`).

## Запуск

```bash
pip install PyQt5 xlsxwriter
cd programm
python EducationalSoftware_ru.py
```

Запускать из папки `programm`: программа хранит состояние в файле `EducationalSoftware.tmp` в текущей директории.

## Структура

- `programm/EducationalSoftware_ru.py` — основная логика и окно приложения;
- `programm/window_bone.py` — разметка интерфейса;
- `programm/initial_data.py` — исходные данные;
- `demonstration/` — скриншоты и реферат.
